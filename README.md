# Nexora company website

A static-first company website for a software, AI, and technology studio, built with Next.js.

## Start locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- `src/app` — Next.js application routes and global styles
- `src/components/home` — composed homepage sections
- `src/components/layout` — shared navigation and footer
- `src/components/ui` — reusable UI primitives
- `src/data` — content data to make future page work faster

## Checks

```bash
npm run typecheck
npm run build
```
